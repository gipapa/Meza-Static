# 光影粒子演出規範

此專案的進階演出偏好花瓣舞的粒子層次、景深環繞與重擊節奏。先讀對應 scene 的攻擊段落，吸收組成與動態；依招式重新設計，避免把它的花瓣、配色或花朵終結直接套到其他屬性。

## 角色與效果

`addActorSprite()` 的 emoji／自訂圖片是攻防角色與 cut-in 立繪。攻擊物使用生成的 light texture、幾何、粒子或能量帶。禁止以 emoji 字元、角色圖片或放大圖示代替攻擊本體。即使以 Graphics 畫出眼睛、嘴巴和角，單一實心卡通頭部沿路平移，仍不符合本專案要求。招式本身需要的形狀仍可由能量構成，例如「大字爆炎」以火焰粒子勾出大字。

龍系的「龍形」可以由彎曲氣流、交錯殘光、鱗光般的細小反射與壓迫感表達，不需要畫一隻具象的龍。鱗光是短暫的小反射點或銳利光片，避免圍成一圈像 UI 徽章。

## 有層次的能量

依畫面需要配合以下構成，無須每招完全相同：

- **亮芯**：細、銳、接近白色，建立能量方向；避免用粗白塊蓋住目標。
- **主色體積**：屬性色的透明能量帶／曲面；寬度與透明度沿路徑漸變，讓起點、前緣與尾端有區別。
- **柔光暈**：使用真正向外衰減的 radial／thread texture、低 alpha ADD 疊色。避免同心實心圓疊成明顯色階。
- **次級運動**：細火花、流動光絲、熱粒子與殘光。讓粒子沿路徑持續前進，而非整組貼圖同步平移。

保留暗背景與負空間，讓最亮的位置落在蓄力核心、能量前緣和命中點。金、紅等輔色只強調特定瞬間，避免彩色粗描邊和滿畫面均勻亮度。

## 時間上的完整性

蓄力時粒子向內匯聚、核心逐步增亮；釋放前先短暫收縮或暗下來。釋放時前緣先走、尾流跟進，殘光留在路徑上並漸淡。命中以局部亮核、方向性火花、衝擊環與鏡頭反應同時交代力量，之後有可見的消散。

參考花瓣舞的 orbit：使用已建立的粒子 sprite 改變位置、透明度與前後深度，形成包圍感。每幀不要建立新 Graphics。生成的柔光 texture、預建的 ribbon 三角網與 sprite pool 都可使用，維持 skill 的手機粒子預算。

`fx.converge()` 預設含 `TEX.petal`，適合花瓣舞，不能只換 tint 當成所有招式的聚氣。非草系用 scene 內的光絲／火花匯聚，或先確認確有共用需求再擴充 helper。

## 驗收畫面

除了七段中點，必看移動中的攻擊、實際命中與最大衝擊後的殘光。用 360／390px、emoji 角色與自訂圖片各確認主體可讀；在 reduced motion 下保留亮芯、流動方向與局部衝擊，降低 shake、旋轉、閃白。

至少看一次連續的蓄力到命中。看不到攻擊、只有白屏；只看到一顆大圖示飛過去；或只有技術測試綠燈，都不足以宣稱符合此視覺規範。
