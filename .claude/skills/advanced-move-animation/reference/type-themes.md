# 屬性 × 招式名稱 → 演出主題對照表

先依**屬性**決定基底，再依**招式名稱關鍵字**調整母題，最後寫進 design brief（`templates/design-brief.md`）。
主色一律使用 `TYPE_COLORS[moveType]`（由 `MoveCinematicData.typeColor` 傳入，scene 內 `hexToNum(this.d.typeColor)`），
下表只補充輔色、粒子母題、背景與節奏。

## 2. 招式名稱關鍵字 → 母題調整

| 關鍵字（範例） | 本體（attack body）演出 | 終結（finale） |
|---|---|---|
| 舞、亂、旋（花瓣舞） | 環繞目標的粒子刃、多波連擊、HIT 計數 | 粒子匯聚成巨大圖騰後砸下 |
| 斬、刃、切、劈 | 多道 `slash()` 交叉、殘影突進 | 一閃：全畫面黑白 + 一道巨大斬線 |
| 拳、踢、擊、衝 | 連打（zoom punch + 定格），衝擊環 `ring()` | 最後一拳：慢動作 → 爆發 |
| 光、束、炮、射 | 蓄力光球 → 粗光束橫越畫面 | 光束貫穿 + 全白 `screenFlash` |
| 雷、電、閃 | 折線閃電從天而降、頻閃 | 巨雷柱 + 畫面反白 |
| 波、潮、浪、泉 | 浪潮從攻擊方湧向目標 | 巨浪吞沒 |
| 爆、焰、炎、燒 | 連續爆炸、火柱 | 大爆炸 + 熱浪 |
| 龍、王、神、逆鱗 | 分層光帶與流動粒子環繞，藉氣流暗示龍威 | 多股能量匯聚俯衝、局部亮核爆散；不射出卡通龍頭 |
| 吸、奪、汲 | 能量從目標流回攻擊方 | 攻擊方發光回復 |
| 毒、霧、粉 | 煙霧籠罩目標，慢性傷害數字 | 霧中爆開 |

## 3. 共通演出語彙（機器人大戰風）

- **開場**：雙人鏡頭 + ATTACK 警告帶 + letterbox，攻擊方被推近。
- **Cut-in**：斜帶，攻擊方立繪（我方從左、敵方從右），台詞 2–3 行；接著逐字蓋章的招式名稱標題卡。
- **蓄力**：攻擊方特寫，集中線、聚氣粒子、氣場、量表 MAX，eye-catch（眼部特寫帶）+ 吶喊，白閃轉場。
- **本體**：至少 3 波命中，中途至少一次切回攻擊方再回目標，dutch angle（`rotateTo`）、HIT 計數、浮動數字。
- **終結**：終結技名稱 + 第二次 eye-catch，最大衝擊（shake + flash + burst）。
- **收尾**：餘韻粒子、防守方傾倒、TOTAL DAMAGE、FINISH、letterbox 收回、淡出。

## 4. 鏡頭與節奏原則

- 一個鏡頭（cut 之間）2–5 秒為主；本體可 1–2 秒快切，但每個 phase 至少要有一個 ≥ 2 秒的穩定鏡頭讓手機玩家看清楚。
- 大衝擊前 300–600 ms 先「收」（放慢、暗場、拉遠），再「放」。
- 文字停留 ≥ 1.5 秒；中文標題字級 ≥ 30px（設計座標 360×640）。
- 尊重 reduced motion：`this.shake()` 已自動停用；大幅旋轉/閃白請用 `this.reduceMotion` 降級。

## 5. 音效方向（目前未實作）

遊戲目前的 cinematic 是靜音的（Phaser config `audio.noAudio`），BGM 由 `src/lib/bgm.ts` 以 Web Audio 合成。
設計時請在 design brief 寫出 **cue sheet**（時間點 → 音效描述），之後若實作音效：
- 以 `src/lib/bgm.ts` 同樣的 Web Audio 合成方式做一個 cinematic SFX 模組，遵守 `isMuted()`；
- 觸發點只能掛在 `this.phase()/this.cue()` 上，跳過（skip）或卸載時必須停止所有聲音；
- 不要依賴外部音檔（離線、檔案大小）。
